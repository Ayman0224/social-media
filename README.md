# Social Media Platform

A full-stack social media platform built as an internship project.
Users can create posts, like and comment on posts, follow other users, and view profile statistics.

##  Live Project

**Frontend:**
https://social-media-frontend-q7ki.onrender.com

**Backend API:**
https://social-media-backend-gfn9.onrender.com

##  Features

* Create and view posts
* Like and unlike posts
* Add comments to posts
* Follow and unfollow users
* Check follow status
* User profile page
* Profile statistics:

  * Number of posts
  * Number of followers
  * Number of following
* REST API backend
* PostgreSQL database
* Responsive frontend design
* Deployed frontend and backend
